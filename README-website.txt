SMART VOLKSWAGEN SPARES WEBSITE

Keep index.html, style.css and script.js together in this folder.
Keep the photos folder alongside them. The six uploaded spare-parts photos
are used by script.js in the gallery. Do not rename them unless you also
change the matching image paths in script.js.

To preview, open index.html in a browser. To publish, upload all three
code files and the entire photos folder to the same website directory.
